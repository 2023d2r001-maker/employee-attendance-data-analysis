# employees attendance data analysis

## Overview

This repository contains a **Power BI report (.pbix)** that delivers interactive dashboards and insights using Microsoft Power BI Desktop. The report was created from a **cloud-based dataset** and is intended for data analysis, visualization, and business reporting.

* **File name:** `power bi project(2023d2r001).pbix`
* **Tool:** Microsoft Power BI Desktop
* **Created from:** Cloud dataset
* **Power BI release:** 2025.11

---

## Objectives

* Provide clear, interactive visualizations for business insights
* Enable stakeholders to explore data using filters, slicers, and drill-downs
* Centralize reporting in a single Power BI file

---

## Key Features

* Interactive dashboards and report pages
* Predefined relationships and measures (managed within the data model)
* Custom visuals included in the report
* Branded static resources (logos and themes)

---

## Data Sources

* Data is connected via **cloud-based connections** (see Power BI *Connections* pane)
* Dataset refresh depends on access to the original cloud source

> **Note:** Credentials may be required to refresh data.

---

## How to Use

1. Install **Microsoft Power BI Desktop** (latest version recommended)
2. Open the file:

   ```
   power bi project(2023d2r001).pbix
   ```
3. If prompted, sign in and provide data source credentials
4. Use slicers, filters, and visuals to explore insights
5. Refresh data from **Home → Refresh** (if access is available)

---

## Customization

* Modify visuals by selecting them and updating fields/measures
* Update themes via **View → Themes**
* Add new report pages as needed
